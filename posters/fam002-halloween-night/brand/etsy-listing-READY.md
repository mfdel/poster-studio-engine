## 1. What this listing sells

One digital pack for one address. The buyer prints it at home on US Letter paper or A4 paper.

**This is not a poster.** It is a sheet on ordinary printer paper that a child carries on the
walk and writes on. Nothing about the listing may frame it as wall art that ships in a tube.

The pack holds two sheets. **One layout sells: `band`.** The other four layouts stay in the code,
but they are not offered, not photographed and not named in the copy.

- **The map sheet (`band`).** The streets and the house footprints within about 400 m of the buyer
  address. The buyer home carries a marker. The child draws the route, colours a treat tally of 40
  boxes, draws the best costume, and names the house they liked best.
- **The spotting sheet (`bonus`).** Sixteen things a child can find on any street. It carries no
  map, so it works in any town. It ships in the same pack at no extra price.

The spotting sheet no longer prints the words "Bonus sheet" at its head. The date holds that line
on its own.

Each sheet ships in two colour ways and two paper sizes.

- `lantern` is the dark night version. It is the screen version and the hero image.
- `ink` is the light version. A home inkjet prints it well. It is the file the buyer sees first.

### The rule that must never break

**The sheet never says which houses give treats.** It never says which houses take part. It never
says which houses are safe. That data does not exist before the evening. A neighbour decides it on
the night, and a porch light is the only signal.

This rule holds in the title, in the description, in the tags, in the photos and in the buyer
messages. Break the rule and you create a refund risk and a review risk.

Nextdoor has run a free crowd-sourced Treat Map for 13 years. This product does not compete there.
This product competes on the object the child keeps afterwards.

## 2. Listing structure — the recommendation

**Sell one listing. Do not use the Etsy Digital listing type.**

The map is rendered for the buyer address after the order. An Etsy Digital listing delivers a fixed
file the moment a buyer pays. That is the wrong promise for this product.

Mirror the pattern the shop already runs. Create a physical, made-to-order listing. Attach a
delivery profile that is free everywhere. Deliver the files by Etsy message. Never write "instant
download" in any field.

**The shop has no free-everywhere delivery profile today.** The live profile is `EU0-US70`. Create
one new profile before you publish.

### The shop currency question

The Etsy shop currency is **SEK**, and it is a **shop-wide** setting. A US buyer sees a converted
price, not a price you chose. 76 SEK shows as 8.01 US dollars today, and as 7.93 or 8.04 next week.

**Recommendation: switch the shop currency to USD.** Four reasons.

1. All three products target the United States. eRank measures USA. Pinterest reaches USA.
2. The shop has 0 orders. This is the cheapest moment the switch will ever be.
3. A clean 7.99 converts better than 8.01 on an impulse buy.

prices such as 36.88 dollars, and you must re-round each one by hand. FAM-001 and PRT-006 hold

after an option edit, so work carefully. Etsy also charges a currency conversion fee when the
listing currency and the payment account currency differ. **Read the current fee on the Etsy fee
page before you switch.**

**This is a founder decision, and it is outside FAM-002.** Do not switch the shop currency as a

## 8. What you render for an order

Run the fetch once for the address, then render the pack from the saved run. The second command
costs no network call.

```bash
uv run python posters/fam002-halloween-night/make.py \
    --address "<buyer address>" --radius 400 \
    --theme lantern --size Letter --layout band \
    --title "<Title> Halloween Night" --night "31 October 2026" --preview

uv run python posters/fam002-halloween-night/render.py --run latest \
    --theme lantern,ink --layout band,bonus --size Letter,A4 \
    --night "31 October 2026" --title "<Title> Halloween Night" --zip
```

**Render the pack in one command.** `--theme`, `--layout` and `--size` each take a comma-separated
list. One command writes one ZIP that holds all 8 sheets. Do not loop the render, one sheet per
call. Each call rebuilds the ZIP from its own sheets, so a loop leaves an archive with 1 sheet in
it.

**Read the last line of the output.** It must say `(8 PDFs + 2 notes)`. Send that ZIP. The file
name states the pack, for example `..._lantern-ink_Letter-A4_band-bonus_digital.zip`.

**Only `band` and `bonus` are rendered.** `panel`, `sheet` and `ledger` still work, but they are
not sold and they are not in the photos. Do not send a buyer a layout the listing never showed.

The pack is 8 PDF files plus 2 notes. `--zip` writes the how-to-print note and the OpenStreetMap
licence note into the archive.

**Check the render before you send it.** If the address has no OpenStreetMap building data, the
renderer prints a warning and the sheet degrades to a clean street map. Message the buyer first.
Use the template in section 10.

### A defect in the pack build

The test render in section 8 ran end to end for the first time. All 8 PDFs rendered. The `--zip`
pack was wrong.

`render.py` builds the ZIP from the PDFs of **one** invocation, and it names the file from the
title and the theme only. The 8-step loop in section 8 therefore overwrites the archive on every
step. The result is 2 archives, one per theme, each holding **1 PDF** and the 2 notes. A seller who
follows section 8 sends a buyer one sheet of the four.

The engine now accepts a comma-separated list for `--theme`, `--layout` and `--size`, so one
command renders the whole pack into one archive. Section 8 holds the new command.

### An editor trap that cost time

A stray click opens a `wt-menu` panel, and that panel sets `overflow: hidden` on `<body>`. Every
later click then fails with "element is outside of the viewport", because the page cannot scroll.
Press `Escape` until `getComputedStyle(document.body).overflow` reads `visible`.

The category control is a `div` with `role="button"` and
`aria-label="Expand to edit category section"`. Click it to expand the section. The search field
inside is `readonly` until you click the `.le-category-search__committed` chip that covers it.
