# Etsy Store Name

## Etsy naming rules (so any pick is valid)

- **4–20 characters**, letters and numbers only — **no spaces, no punctuation**.
- Must be **unique** (Etsy blocks taken names) and shouldn't infringe a trademark.
- You get a separate **Shop Title / tagline (up to 55 chars, spaces allowed)** shown under the name —
  use that for keywords (see [store-description.md](store-description.md)).
- **Before committing:** check availability on Etsy sign-up, and grab the matching `.com`/Instagram
  handle if you can. Search the name on Etsy + Google first to avoid an existing shop or brand.

> Recommendation: pick a name that is **evocative and ownable** (the brand), and let the **Shop Title**
> carry the SEO keywords ("personalized playground map, new baby gift…"). Don't cram keywords into the
> shop name itself — it looks spammy and boxes the brand in.

## Naming rationale (how to choose)

1. **Ownable > descriptive.** The moat is a distinctive brand, so favor a name with personality
   (`HopscotchMaps`, `OurLittleMap`) over a literal one (`PlaygroundMapShop`). Keywords go in the
   Shop Title, not the name.
2. **Warm, not techy.** Avoid anything that sounds like a utility app or GIS tool.
3. **Room to grow.** If you later add nursery prints or other family keepsakes, a name like
   `OurLittleMap` or `HopscotchMaps` stretches; `SwingAndSlideCo` is more boxed-in to playgrounds.
4. **Say-it / spell-it test.** If you can say it to another parent and they can spell it back, it's
   good. All shortlisted names pass.
