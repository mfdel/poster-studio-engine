# Etsy "Celebration" Attribute — Occasion Calendar

*Companion to [roadmap_etsy_traffic_20260801.md](roadmap_etsy_traffic_20260801.md) (Phase 5 — seasonality).
The Etsy **Celebration** attribute is single-select, so it must be **rotated** through the year, and
seasonal **tags** should be swapped in **~6–8 weeks ahead** of each date. This table lists all 22 options
from Etsy's picker with the **next occurrence from today (2026-08-01)**.*

> **Date accuracy:** Fixed-date and US floating holidays are exact. Dates marked **≈** are moveable feasts
> (Jewish / Hindu / Islamic / lunar calendars). Islamic dates (Ramadan, Eid) depend on **moon sighting**
> and can shift ±1–2 days — **confirm nearer the time.**

## What this means for HopscotchMaps (action)

For a **personalized family keepsake / new-parent gift**, only a few of these move the needle. Rotate the
single **Celebration attribute** and swap seasonal **tags** on this cadence (start ~6–8 weeks before):

| Season | Set Celebration attr → | Start prep (~6 wk before) | Seasonal tag to swap in |
|---|---|---|---|
| **Autumn/Winter** | Christmas | **mid-Nov 2026** | `christmas gift kids` |
| **Late winter** | Valentine's Day *(optional)* | early Jan 2027 | `valentines gift` |
| **Spring** | Mother's Day | **late Mar 2027** | `mothers day gift` |
| **Early summer** | Father's Day | **early May 2027** | `fathers day gift` |

**Reminder:** don't duplicate the active Celebration attribute value as a bare tag (Etsy counts
attributes like tags). Use the tag slot for a *different* phrase, and keep the year-round gift/occasion
tags (`baby shower gift`, `first birthday gift`, `grandparent gift`) constant underneath the seasonal one.
